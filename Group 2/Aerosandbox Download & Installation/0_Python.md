# Python Installation

### Install Python Correctly (The 64-bit Mandate)

1. Go to the [official website](https://www.python.org/downloads/windows/).

2. Ensure you download the **Windows Installer (64-bit)**.
   > **Note:** If you click the generic "Download" button on the main homepage, it sometimes downloads the 32-bit version by default. 32-bit Python cannot run modern scientific packages like SciPy.

3. When running the installer, you **MUST** check the box at the bottom that says **"Add python.exe to PATH"**. If you skip this, your command prompt will not recognize Python commands.

4. Complete the installation.
