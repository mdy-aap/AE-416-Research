# Create an Isolated Virtual Environment <br>     - Open your terminal (Command Prompt on Windows, Terminal on Mac/Linux).     - Navigate to your project folder:        ```         cd path/to/your/uav-propulsion-optimizer    - Create the virtual environment (we will name it uav-env):          ```         python -m venv uav-env    - Activate the environment:        - Windows (Command Prompt):           ```            av-env\Scripts\activate       - Mac / Linux:           ```            source uav-env/bin/activate       - Troubleshooting: "Running scripts is disabled on this system" (Windows PowerShell Only)           - Temporary Bypass (Highly Recommended) Run this command in your active PowerShell terminal to lift the restriction for just your current session (it automatically restores default security when you close the terminal):              ```               Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process          - After running this, execute the activation script again:              ```               uav-env\Scripts\activate    - If done correctly, you will see (uav-env) at the left side of your terminal.
